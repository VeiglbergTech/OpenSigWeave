## Boundaries and deployment

- Each provider ID uses the original ASCII slug validator, including when reading cached providers. Registry root and provider components are opened with O_DIRECTORY and O_NOFOLLOW and pinned as directory descriptors. Only .env is read, atomically replaced and unlinked; recursive deletion is removed.
- Provider files must be regular, privately readable, owned by application UID, single-link and at most 128 KiB; files previously written with the original 0600 mode remain compatible.
- Backup operator still runs root on the host with Docker access and age secrets; the app only mounts the Unix socket file. BACKUP_APP_UID must match the container effective UID. The host socket directory remains root-only; SO_PEERCRED remains mandatory.
- #19 is deliberately insecure test input, not an application permission. Do not erase this security regression test just to influence the scanner.
- Real NFS/SMB remote mount behavior and end-to-end restore remain operational acceptance criteria; isolated unit tests do not establish this.
